# g857_manual.txt

Manual G-857 layout, three columns, hand-entered from the instrument display.

- Instrument: Geometrics G-857
- Source: layout specified by the instrument owner (J. Maurer), 2026-08-26

Columns: `station`, `time`, `value_nT`. Header line is uncommented, so header
detection must not require a comment prefix.

Note the column order differs from the exported layout — time precedes the
field value here, and there is no line or quality column. This is why layout is
resolved from the header rather than assumed.
